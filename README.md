# Контакт — CodeRivento

Сайт ремонтной мастерской и интерактивная CRM для портфолио. React 19, TypeScript, Vite, Tailwind CSS и Radix UI.

Сайт: https://reizanskl.github.io/kontakt-workshop/

CRM: https://reizanskl.github.io/kontakt-workshop/crm/

## Возможности

- Доска заявок с перетаскиванием между этапами: новая, диагностика, в ремонте, готова. Выданные устройства переходят в архив.
- Создание и редактирование ремонта: устройство, неисправность, мастер, срок, стоимость, приоритет.
- История смены статусов и комментарии по заявке.
- База клиентов с контактами, заметками и историей обращений. Повторные заявки связываются по телефону.
- Поиск, фильтры по мастеру и устройству, срочные заявки, табличный вид и выгрузка CSV.
- Форма на сайте создаёт заявку в CRM того же браузера. Уже открытая вкладка CRM обновляется автоматически.
- Адаптивная вёрстка, управление с клавиатуры и восстановление начальных примеров с подтверждением.

## Данные и размещение

Приложение работает на статическом GitHub Pages. Изменения сохраняются в `localStorage` по ключу `kontakt:crm:v1`, остаются после обновления страницы и синхронизируются между вкладками одного браузера. В другом браузере или на другом устройстве будет отдельный набор данных. Начальные записи вымышлены.

Общей серверной базы, авторизации сотрудников и отправки в Telegram в этой версии нет. Для приёма реальных заявок разных пользователей потребуется backend. Секреты и персональные данные реальных клиентов для просмотра портфолио не нужны.

## Локальный запуск

Требуется Node.js 24 или новее.

```sh
npm ci
npm run dev
```

## Сборка

```sh
npm run build
npm run preview
```

Статические файлы находятся в `dist`. Сайт, «О проекте» и CRM собираются отдельными HTML-входами (`index.html`, `about/index.html`, `crm/index.html`). Прямой переход и обновление работают без серверного роутера. Ресурсы используют относительные пути для размещения в подпапке GitHub Pages или на отдельном домене.

## Проверка

`npm test` проверяет создание и привязку заявок, переходы статусов, историю, валидацию, схему хранилища, поиск и защиту CSV от формул. `npm run build` включает проверку TypeScript. Перед публикацией также проверены основные действия в браузере и ширины 320–1920 px. Концепты и сравнение реализации находятся в `design/crm`.

## GitHub Pages

В настройках репозитория: **Settings → Pages → Source → GitHub Actions**. Публикация выполняется автоматически после изменений в `main`. Рабочий процесс находится в `.github/workflows/pages.yml`.

Шрифты находятся в `public/fonts` и распространяются по лицензии OFL. Фотография подготовлена для этого проекта. Серверные модули, токены, пароли и настройки прежнего хостинга в эту версию не входят.
