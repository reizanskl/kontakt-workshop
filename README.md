# Контакт — CodeRivento

Сайт ремонтной мастерской для портфолио. React, TypeScript, Vite и Tailwind CSS.

## Форма

Кнопка показывает локальное состояние «Заявка отправлена» после проверки полей. Это имитация интерфейса: запросы на сервер не выполняются, данные не сохраняются, Telegram не подключён. Для настоящего приёма обращений нужен отдельный обработчик.

## Локальный запуск

Требуется Node.js 24 или новее.

```sh
npm ci
npm run dev
```

## Сборка

```sh
npm run build
npm run preview
```

Статические файлы находятся в `dist`. Страница «О проекте» собирается отдельно в `dist/about/index.html`; прямой переход и обновление страницы работают без серверного роутера. Ресурсы используют относительные пути, поэтому сайт работает как в подпапке GitHub Pages, так и на отдельном домене.

## GitHub Pages

В настройках репозитория: **Settings → Pages → Source → GitHub Actions**. Публикация выполняется автоматически после изменений в `main`. Рабочий процесс находится в `.github/workflows/pages.yml`.

Шрифты находятся в `public/fonts` и распространяются по лицензии OFL. Фотография подготовлена для этого проекта. Серверные модули, токены, пароли и настройки прежнего хостинга в эту версию не входят.
