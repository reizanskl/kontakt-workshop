# Контакт CRM: визуальная спецификация

Основной референс: `board-concept.png`, детальная карточка: `detail-concept.png`. Концепты созданы встроенным Image Gen по задаче CRM для мастерской: заявки, клиенты, статусы ремонта, полноценные интерактивные состояния.

- Холст: тёплый белый `#f6f5f0`; боковая панель `#183e35`; активная навигация `#d7ed9b`; поверхности `#fff`; границы `#dce2d9`; основной текст `#17201e`; вторичный `#68736f`.
- Manrope: заголовок 38/46, карточка 18/25, элементы управления 14/20, подписи 12/18. На телефоне заголовок 28/34, управляющие элементы не менее 40px.
- Боковая панель 224px, верхняя строка 56px, поля контента 28px. Рабочая область без внешней карточки. Четыре колонки, карточки 12px, граница 1px, небольшая тень.
- Иконки Lucide: outline 18–20px, 1.7px stroke; семантические точки статусов и инициалы мастеров. Без фотографий в CRM.
- Состояния: доска/таблица, клиенты, архив, создание заявки/клиента, правый drawer заявки/клиента, редактирование, история, пустые результаты, подтверждение сброса.
- Основной путь: заявка с сайта → новая карточка → диагностика → ремонт → готовность → выдача/архив; карточка клиента связывает все его обращения.
- Поля формы и данные рисуются кодом. Цифры и даты считаются по текущему локальному набору, поэтому могут отличаться от концепта. Дополнительные формы и таблицы используют те же шрифт, контролы, границы и цвета.
- На мобильных sidebar превращается в верхнюю навигацию; доска имеет горизонтальный скролл внутри рабочей области, drawer занимает экран. Смена статуса доступна без перетаскивания.
- Хранение в localStorage с версией схемы; никаких аккаунтов, реальных клиентов или сервера. На публичном сайте нет навязчивых баннеров о демонстрации.

## Проверка соответствия, 18 октября 2026

Концепты и реальные снимки доски/карточки сопоставлены при одинаковом размере 1536×1024.

1. Силуэт: сохранены фиксированная левая панель, тонкая верхняя строка и четыре равные колонки.
2. Иерархия: заголовок, отдельная строка из четырёх показателей, поиск/фильтры и переключатель вида идут в том же порядке.
3. Цвета: тёмно-зелёная навигация, лаймовый активный пункт, тёплый фон, белые карточки и цветовые метки этапов перенесены в CSS.
4. Карточки: номер и срочность сверху, устройство и неисправность, разделитель, клиент, срок, сумма и инициалы мастера. Кнопки добавления выровнены по нижнему краю колонок.
5. Детали: боковая панель справа, затемнение фона, четыре этапа, изменение статуса, блок ремонта и история с комментариями.
6. Шрифты: Manrope с настоящими текстовыми элементами вместо растрового текста. Подписи компактнее концепта, чтобы помещались реальные длинные имена и устройства.
7. Осознанные отличия: сумма 85 500 ₽ вычисляется из примеров, даты относительны текущему дню; добавлены реальная прокрутка длинной колонки, источник заявки и сообщение о сохранении в браузере.

В браузере проверены создание/редактирование, перетаскивание, история, выдача и архив, клиенты, CSV, поиск/фильтры, повторная загрузка и заявка с сайта в другой вкладке. Мобильная таблица прокручивается внутри своего контейнера; при ширинах 320, 390, 768, 1024, 1536 и 1920 px внешнего горизонтального переполнения нет.
